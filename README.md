# Como Usar o Ambiente Virtual (venv)

Este projeto utiliza um ambiente virtual Python para gerenciar dependências.

## Ativar o Ambiente Virtual

Para ativar o venv, execute o seguinte comando no terminal:

```bash
source .venv/bin/activate
```

Após ativar, o prompt do terminal deve mostrar `(venv)` no início.

## Desativar o Ambiente Virtual

Para sair do venv, execute:

```bash
deactivate
```

Isso retornará ao ambiente Python global do sistema.

## Usar o terminal

```bash
python main.py
```

## Ler o ficheiro entrada.lf

```bash
python main.py entrada.lf
```
